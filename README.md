# Cumme

Cumme è una startup che sviluppa esperienze per adulti più immersive grazie all'intelligenza artificiale:
un compagno conversazionale AI che dialoga con l'utente e pilota in tempo reale dispositivi (sex toy) già
esistenti sul mercato.
